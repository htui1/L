# Ashfall Table — بوت ديسكورد

بوت لعبة كذب/بلاف (نفس فكرة "Liar's Bar" اللي بالصورة) بطابع ناجين-على-جزيرة بألوان رصاصية.

## القواعد باختصار
- كل جولة يُحدد نوع مستهدف (A / K / Q / J).
- اللاعب الحالي يلعب ١–٣ بطاقات من يده **بشكل سري** ويدّعي إنها كلها من النوع المستهدف (قد يكذب).
- اللاعب التالي بالدور يختار: **تصديق** (يمرر الدور، والادّعاء يُتجاهل بدون كشف) أو **تكذيب** (تُكشف البطاقات).
- عند الكشف: لو الادّعاء صحيح (كل البطاقات مطابقة أو جوكر)، **المكذّب** يخسر ويسحب من مسدسه. لو كان كذب، **صاحب الادّعاء** هو اللي يسحب.
- كل لاعب عنده مسدس خاص فيه ٦ غرف وطلقة وحدة بمكان عشوائي سري — ما يُعاد تعبيته. كل مرة يسحب فيها، الاحتمال يزيد لأنه ما يعيد التدوير. لو صار عنده ٦ سحبات خاسرة أكيد بينكشف مكان الطلقة قبل او عند السحبة السادسة.
- آخر لاعب باقي (ما انطلقت عليه الطلقة) هو الفائز.

## التشغيل
1. أنشئ تطبيق بوت من [Discord Developer Portal](https://discord.com/developers/applications)، فعّل **applications.commands** و **bot** scopes، وادعِ البوت لسيرفرك بصلاحية إرسال رسائل واستخدام أوامر السلاش.
2. انسخ `.env.example` إلى `.env` وعبّي:
   - `DISCORD_TOKEN` من صفحة Bot
   - `CLIENT_ID` من صفحة General Information
   - `GUILD_ID` (اختياري، لتحديث فوري للأوامر أثناء التجربة على سيرفر واحد)
3. ثبّت المكتبات:
   ```
   npm install
   ```
4. سجّل أوامر السلاش:
   ```
   npm run deploy
   ```
5. شغّل البوت:
   ```
   npm start
   ```

## الأوامر
- `/table` — يفتح طاولة جديدة بالروم الحالي (يفتحها من يكتب الأمر، وهو المضيف).
- `/table-end` — ينهي الطاولة الحالية (للمضيف فقط).

## ملاحظات
- الحد الأقصى ٤ لاعبين حاليًا (بسبب حجم الدِك 26 بطاقة و5 بطاقات لكل لاعب بالجولة). لزيادة العدد، كبّر عدد النسخ من كل رتبة داخل `src/game/deck.js`.
- يد كل لاعب تُعرض له فقط عبر رسالة **ephemeral** (خاصة)، والباقي يشوفون بس الادّعاء العلني.
- الحالة محفوظة بالذاكرة فقط (Map لكل روم) — لو البوت أعيد تشغيله تنتهي كل الطاولات النشطة.
